# WB驭档·模型智能换挡系统网关 · 快速上手（用户版）

> **一句话**：该用哪个模型、这一步花多少钱——它先给你一份计划，**你点头才花钱**。
> 版本 1.0.3.15 ｜ 适合：不会写代码、但会复制粘贴命令的人 ｜ 想省事：把同目录的《Agent 安装说明》整份丢给你的 Agent，让它替你装。

---

## 一、它能帮你做什么（三条就够）

1. **不再瞎选模型**：它按任务把活切成 2–3 段，每段推荐一个模型，还告诉你大概多少钱。
2. **花钱看得见**：执行前先看计划，执行后自动对账（预估 vs 实付）。
3. **换模型不丢上下文**：同一段对话里换模型，前面聊过的还在，不用重说。
4. **云端、本地模型都能接**：云端模型能接，OpenAI 协议的本地模型（如 Ollama、vLLM）也能接。
5. **选模型讲分工**：大模型做设计、小模型做执行、专业模型做专业事；同样够用时，再挑更便宜的那个。

## 二、装好只要三步

**准备**：一台 Linux 电脑或容器（Windows/macOS 原生暂未验证）；已装 Python 3.12；一个模型服务（云端 API 或本地 OpenAI 兼容服务都行，本地常见如 `http://<局域网IP>:11434/v1`）。

### 第 1 步：解包

```bash
mkdir -p ~/wb-router && cd ~/wb-router
tar -xzf gateway-1.0.3.15.tar.gz
tar -xzf plugins-1.0.3.15.tar.gz
tar -xzf skill-mcp-1.0.3.15.tar.gz
ls
```

看到 `gateway  plugins  skill-mcp` 三个目录就是对的。

### 第 2 步：填两个地方

**（a）改配置文件**：`gateway/upstreams.json`（网关根目录） 里把三处换成你自己的：

| 改什么 | 改成什么 |
|---|---|
| `base_url` | 你的模型服务地址（一般以 `/v1` 结尾） |
| `api_key_env` | 放密钥的**环境变量名**（不是密钥本身），例如 `MY_KEY_A` |
| `models` 里的模型名 | 你那边真实可用的模型名 |

`gateway/config/routing.json` 里把 `routes` 中的 `up-x/model-y` 换成你上面写的「服务商/模型」；不会改就先用包里的样例跑通再换。

**（b）放密钥**（只在终端里设，别写进文件）：

```bash
export MY_KEY_A='你的密钥'
```

### 第 3 步：启动并自检

```bash
cd ~/wb-router/gateway
python3 -m pip install PyYAML requests    # 只需第一次
python3 main.py
```

另开一个终端：

```bash
curl -s http://127.0.0.1:18790/health
```

看到 `"ok": true`，且你配的服务商都是 `"state": "ok"` ⇒ **装好了**。

> 打不开管理界面就用：`http://127.0.0.1:18790/admin`（只在本机/内网能开，默认账号见发布说明）。
>
> **费用说明**：生成计划不收费；只有你点「确认开工」后才真正调用模型、产生费用，费用按服务商的真实用量计。预计金额是估算，用来帮你决策，不等于账单。

## 三、怎么开始用

1. **在插件里用**：DSH 模型选择里选网关提供的模型（`auto` / `auto-fast` / `auto-strong`）→ 输入任务 → 点「生成计划」。
2. **看计划、点确认**：计划卡上每段写着用哪个模型、大概多少钱；不满意可以给某段换模型；点「确认开工」才真的花钱。
3. **跑完对账**：打开 `/admin/live` 看运行状态与花费；打开 `/admin/review` 或 `/v1/route/report` 看「预估 vs 实付」。

也可以不装插件，任何支持 OpenAI 接口的客户端直接连 `http://127.0.0.1:18790/v1`，密钥用管理页里新建的那把。

## 四、常见问题（6 条）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 启动报 `Address already in use` | 18790 端口被占 | `ss -ltn \| grep 18790` 找到旧进程停掉；或 `ROUTER_PORT=18791 python3 main.py` 临时换端口试 |
| 所有请求 401 | 没带密钥或密钥不对 | 请求头写 `Authorization: Bearer <你的key>`；换 key 后**重启客户端** |
| 计划里某段显示「0（待用户录入）」 | 那个模型没填价格 | 在 `config/pricebook.json` 补该模型单价，或按页面提示补录 |
| 换了模型，前面聊的还在吗 | 在 | 同一段对话里换即可；它会只换「这一段由谁答」，历史照常带上 |
| 管理界面打不开 | 管理面只在内网 | 在网关那台机器上开 `127.0.0.1:18790/admin`；别把管理面暴露到公网 |
| 想升级或退回 | 升级要合并配置 | 先备份 `config/` 与 `数据/`，再解新包；回滚＝还原备份文件后重启 |

## 五、更省心的用法：把安装交给 Agent

如果你有自己的 AI Agent（Claude Code、Codex、Cursor、元宝类都行），**把同目录的《Agent 安装说明》整份复制给它**，它会：

1. 先检查环境（Python、端口、目录）；
2. 问你三个问题（模型服务地址、密钥、要接哪几个模型）；
3. 自动解包、写配置、设环境变量、启动、跑自检；
4. 把「装好了／哪里卡住」按固定格式回报给你。

你只需要：准备好密钥、回答它三个问题、最后看一眼 `/admin` 页面。

---

## 六、你要知道的边界

1. **默认只本机可访问**：网关只监听 `127.0.0.1:18790`，管理面只在内网；要对外请自行加反向代理并只放行 `/health` 与 `/v1/*`。
2. **密钥只在环境变量/内存**：不写配置文件、不进账本；账本只记请求特征，不存对话内容。
3. **价格表要你自己维护**：`config/pricebook.json` 是唯一价格来源，没填价的模型会显示「待录入」，不会瞎算。
4. **已于 2026-11-22 开源**：仓库 `https://github.com/beidou6972yh/dsh-bw-router`、许可证 **MIT**；Windows/macOS 原生安装暂未验证。
