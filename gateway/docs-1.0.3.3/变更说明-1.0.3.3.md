# 1.0.3.3 变更说明（对侧交付版）

> 1.0.3.3 = **融合前序版本成果**（1.0.3.2 全部能力）＋ 1.0.3.3 遗留收口（审计补全 / 回归锁行为 / 标定报告 / L9 销账 / 真源回改）。用户 2026-11-21 21:59 拍板口径：「融合前序版本成果，升版 1.0.3.3」。
> **网关主代码（`main.py` / `router_*.py` / `admin_ui.py`）相对 1.0.3.2 零功能性改动**；差异仅在测试、运维工具、观测参数与文档（见第 2 节），生产行为与 1.0.3.2 等价。

## 1. 能力清单（沿用 1.0.3.2，全部保留）

- **B1 边界纪律**：plan 每段只读 `boundary_policy`；annotation 可带 `turn_ctx`；`GET /v1/route/discipline?range=` 只读聚合（同轮工具轮换模记 `discipline_violation`，不阻断；治理/守门/回退可 `exempt`，判据看非豁免计数）。
- **B2 复盘/回放**：`GET /v1/route/report?range=&group=`（预估 vs 实付＋账本实账，尾部 1MB 标 partial）；`POST /v1/route/replay`（只读复算、0 执行 0 写账）；`/admin/api/report`、`/admin/review` 页。
- **B3 自动化档位**：body/头 `automation_level=L1|L2|L3`（L1=现状、不传即零变化）；plan 返回 `automation` 块；档位只改确认节奏，不改选模。
- **B4 影子判定**（默认关）：`GET /v1/route/shadow?range=`；`/health.shadow` 仅开启时出现；异步、失败丢弃、不改选模。
- **B5 只读兼容入口**（默认关）：`X-WB-Route-Mode: passthrough`＋per-key 开通；响应头 `X-WB-Model/Strategy/Usage-Kind`。
- **A0/L5 价格单源**：`config/pricebook.json` 为唯一真源；`ROUTER_PRICE_ATTEST=1` 默认单源自证；DSH 价格表由脚本生成。
- **R4/R5 上下文治理**：`context_governor`（默认 `shadow`）；预算 = `window − max(1024, ceil(0.2×window))`；CJK 保守估算（CJK 1.0 / 非 CJK 4.0 / 图 1000）；本地 cap 仅输入、默认关；阶梯裁剪默认关；超窗结构化 400 `context_window_exceeded`（413 仅开关）；超时收回 read 270s / stream 600s（数据驱动）。
- **观测**：账本 `ctx_gov`；响应头 `X-DSH-Context-Window/-Budget/-Used/-Used-Kind`、`X-DSH-Trimmed`、`X-DSH-Band`。

- 本包 config 为**匿名样例**，不含任何真实上游/模型价格/凭据；安装后请替换为你侧配置。
- 默认开关：B4/B5/trim/413 关，`context_governor=shadow`；开启步骤见 `docs-1.0.3.3/开关开启与观察.md`。
