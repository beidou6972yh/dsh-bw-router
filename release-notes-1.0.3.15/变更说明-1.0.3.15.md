# 变更说明 · 1.0.3.15（2026-11-27）

> 上一版 1.0.3.13 发布后，对侧独立二次复核判定「仍有残留」；本版按实测逐项销账并重出。

## 一、本版做了什么

1. **整族内部任务号清零**：公开包与仓库源码中 整族内部任务号（日期编号 .DSH 全族）一律泛化为中性描述；脱敏闸新增 `internal-task-family` 规则防复发。
2. **历史包内内部文档清零**：公开包不再夹带内部执行记录、内测编号（早期问题序号）、被清空的反引号占位残句，以及内部文档引用。
3. **修插件鉴权兜底缺陷**：公开插件不再内置任何部署路径或凭据文件名；鉴权只认显式注入的 `WB_GATEWAY_API_KEY` / `WB_GATEWAY_KEY_FILE`，两者都缺失时明确返回 503，不再静默发出无鉴权请求；annotations 改为可选增强，仅显式配置 `WB_ANNOTATIONS_FILE` 时读取。
4. **署名统一**：npm 子包 `author` 统一为 `B&W`。
5. **发版卫生**：旧 tag 资产不再改动（1.0.3.15 起，改包一律发新 tag）；本版 release 说明附 64 位 SHA256SUMS 校验清单，供下载方锚定。

## 二、兼容性

- 产品代码功能零改动（仅公开件文案、默认值与脱敏工具）；网关回归两段各 596 例全绿。
- 已按 `1.0.3.13` 安装的生产环境：若产品代码与 1.0.3.15 逐字节相同，无需重启；升级依赖方按新 tag 取包即可。
- 插件使用方需确保宿主注入 `WB_GATEWAY_API_KEY`（或 `WB_GATEWAY_KEY_FILE`）；不再有隐式默认路径。

## 三、验证

- 脱敏闸：13 条规则全部 PASS，公开件 0 命中；npm 单包逐个过闸。
- 包内逐文件 SHA256SUMS 重算、顶层 `SHA256SUMS.txt` 4 行 64 位自检、解包复扫。

*本说明不含任何真实金额、账户名、内网地址、内部路径与内部任务名。*
