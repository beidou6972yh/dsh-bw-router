# 包内校验与安装说明（1.0.3.3 净化包）

## 一、校验
- 每个 tar 包**根目录**有 `SHA256SUMS`（列出包内全部文件，`SHA256SUMS` 自身不在清单内）。
- 解包后在该目录执行：`sha256sum -c SHA256SUMS` ⇒ 应全部 `OK`。
- 包外另有 `<包名>.SHA256SUMS`（与包内清单一致，可直接比对）和 `SHA256SUMS.txt`（三个 tar 包的 sha256）。
- 若有任何文件 `FAILED` 或 `No such file`，**不要安装**，先对包外 `SHA256SUMS.txt` 核 tar 包本身。

## 二、安装
1. 解包到目标目录；`config/` 内是**匿名样例配置**（`up-a/up-b/up-c/up-d/local-lan`，域名 `.example.com`，key 用环境变量名占位），
   **请替换为你侧真实配置**后再启动；样例仅供启动/回归用。
2. 运行回归：`bash run-tests.sh --clean --config-dir config`（本包实测两段均 `Ran 568 / OK`，因匿名配置的用例展开数与生产配置不同，**以两段一致+全绿为准**，不要求固定 568）。
3. 启动：`python3 main.py`（默认 `127.0.0.1:18790`），`curl /health` 应 200。
4. 价格：`python3 scripts/price-attest.py` 应 `consistent`；DSH 价格表生成用 `scripts/export-dsh-model-prices.py`。
5. 开关默认与开启步骤见 `docs-1.0.3.3/开关开启与观察.md`。

## 三、本包不含
- 真实上游清单 / API Key / 凭据 / 数据目录 / 日志 / 余额。
- 生产 `pricebook.json`、`deciders.json` 等含真实模型与价格的配置（请用你侧数据生成）。
