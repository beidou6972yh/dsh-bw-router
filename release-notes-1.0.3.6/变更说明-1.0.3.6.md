# 变更说明 1.0.3.6（2026-11-24）

> 1.0.3.5 未单独发布；本版包含 1.0.3.5 的交付一致性修复 + 1.0.3.6 的四项收口。
> 路由算法、账本字段、计划/确认/执行流程不变。

## 一、1.0.3.6 增量（本版重点）

1. **价目支持币种**
   - `config/pricebook.json` 顶层 `currency` 是默认币种；单个 offer 可用 `"currency": "USD"` 覆盖（兼容 `price.currency` / `meta.currency`）。
   - `plan` 成本一律折人民币、保留 3 位小数；非 CNY 报价缺 `config/fx-rates.json` 汇率时判「价未知」（`cost=null, known=false, unconverted_currency`），**不猜价**。
   - `/v1/route/prices` 的 `list/effective/best` 三视图透出报价币种；样例新增 USD 报价 `model-usd-fast`（`up-c/model-usd-fast`，不可路由，仅演示比价与折算）。
2. **AFP 快照统计口径**：同一份坏内容重复读取时 `snapshot_missing` **每次**计数（此前只计首次）；只影响观测，不改变「解析失败 ⇒ 保守放行」。
3. **回归用例订正**：`test_read_and_mtime_cache` → `test_read_and_content_cache`，补 mtime 断言（mtime 变、内容不变 ⇒ 复用解析；内容变 ⇒ 立即新值）。
4. **发布可核**：打包产出 `SHA256SUMS.txt`（三包 sha）与 `RELEASE-SHA256.txt`（64 位整串），发布说明直接引用整串、不再手输；打包脚本对 sha 长度/格式做自检。
5. **公开包脱敏**：内部路径、内部文档名、内部模型名清零；`gateway` / `plugins` / `skill-mcp` / `docs-open` 全部 `opensource-leak-scan` **0 命中**。
6. **文档与版本**：README/使用说明书/安装说明刷新；插件版本统一 **0.2.2**（代码与 0.2.1 等价）；新增 `gateway/INSTALL.md`；仓库只带 `config/api-keys.example.json` 样例。

## 二、1.0.3.5 同批（首次随本版公开）

1. **默认端口统一 18790**：`main.py` 默认值与 README / MCP / Skill 文档一致（此前 8790）；`ROUTER_PORT` 可覆盖。
2. **内置 `config/fx-rates.json` 样例**：USD 上游不再「有价却估不出」；缺键/为 null 仍判「价未知」。
3. **交付一致性**：插件版本、顶层 `SHA256SUMS.txt`、`check-tools.sh` 路径解析、`install-dsh.sh` 回显 `DSH_HOME`、MCP 去客户端预检。
4. **匿名 `config/pricebook.json` 样例**：开箱 `plan` 可出示例价（明确标注样例，非真实供应商价）。
5. **`annotations.totals` 增 `currency` / `unpriced_rows` / `foreign_currency_rows`**；每个分组桶带 `currency`，跨币种不再静默按 0 相加。
6. **价格三态 `local`** 改为本地 provider 集合判定（`provider_b` / `local-lan` / `local` / `localhost`）。
7. **AFP 快照缓存改内容字节比较**：根治「同 mtime 同 size 内容变却命中旧值」；写端非原子读到半文件 ⇒ None（保守放行）。

## 四、回滚

- 仓库：`git checkout v1.0.3.3`（上一个公开版本）；包继续用 `v1.0.3.3` Release 资产（不删除）。
- 本机生产网关：升级前已备份代码与 VERSION，回滚＝恢复 `tools/router-gateway-v1.1d3` 的 `*.bak-261124-pre-1036` 并重启。

## 五、口径说明

1. **计划有效期**：plan 记录按 24h 留存，宿主重启后内存态计划失效（可重新 plan；账本/annotation 不受影响）。
2. **确认闸位置**：`wb_route_execute` 强制 `confirmed=true`（MCP/Skill 层）；网关 `POST /v1/chat/completions` 是通用代理入口，不含确认语义。
3. **样例上游 `.example.com` 占位**：`execute` 返回 502 属预期（未接真实上游）。
4. **USD 样例不可路由**：`model-usd-fast` 只用于验币种与折算，不参与选模；接真实 USD 上游后把它加进 upstreams/路由即可。
