# 测试清单 1.0.3.6（给对侧复测）

> 目标：验证 1.0.3.6 的四项收口与 1.0.3.5 的交付一致性修复；判据以「命令输出」为准。

## 一、包与校验

1. 下载三件包与顶层 `SHA256SUMS.txt`，`sha256sum -c SHA256SUMS.txt` 全 OK。
2. 每包解压后 `sha256sum -c SHA256SUMS` 全 OK（gateway / plugins / skill-mcp 各自）。
3. `plugins-1.0.3.6.tar.gz` 内 `dsh-wb-pro/package.json`、`dsh-wb-max/package.json` 版本均为 **0.2.2**。
4. `RELEASE-SHA256.txt` 每行 sha256 为 **64 位十六进制**（可用 `awk '{print length($1)}'` 逐行核）；与 `sha256sum <包>` 一致。

## 二、开箱

5. `python3 main.py`（不设 `ROUTER_PORT`）实际监听 **127.0.0.1:18790**；`curl /health` → 200。
6. `gateway/config/` 内 `fx-rates.json`、`pricebook.json` 存在且为匿名样例；`POST /v1/route/plan`（带 task）→ 200 且至少一段 `cost_known` 不为 null。
7. **USD 样例可验**：`curl -s '127.0.0.1:18790/v1/route/prices?model=model-usd-fast'` → `aggregate.offers[0].pricing.currency == "USD"`，且 `prices` 有入/出数字。
8. **缺汇率不猜价**：`python3 -m unittest tests.test_fx -v` 全绿（含「USD 报价缺汇率 ⇒ cost=null/known=false」用例）；把 `fx-rates.json` 的 `USDCNY` 置 null 后重启，`plan` 中若选中非 CNY 模型应判价未知。

## 三、MCP / Skill / 安装

9. `skill-mcp/wb-max-router/scripts/check-tools.sh` 在任意目录执行均能定位 `server.mjs`（不依赖固定安装路径），输出 `✅ 3 = 3`。
10. 网关未开鉴权时，MCP `wb_route_plan` / `wb_route_execute(confirmed:true)` 直接可用；给网关设 `ROUTER_API_KEY` 后，不带 key 调 MCP 应返回 401 且带可操作提示。
11. `scripts/install-dsh.sh --yes`（或 dry-run）首屏打印 `DSH home（可被 DSH_HOME 覆盖）：<路径>`。

## 四、回归

12. `cd gateway && bash run-tests.sh --clean --config-dir config` → 两段各 `Ran 579 / OK（skip 1）`、失败集合一致、总 exit 0；canary 段 exit 1（按预期红）。
13. 仓库根 `npm ci && npx vitest run` → 43 files / 532 tests 全绿。
14. AFP 统计口径：`python3 -m unittest tests.test_afp -v` 全绿（坏内容重复读 ⇒ `snapshot_missing` 每次计数）。

## 五、口径

15. `/v1/route/report` 返回的 `annotations.totals` 含 `currency:"CNY"`、`unpriced_rows`、`foreign_currency_rows`。
16. `/v1/route/prices` 的本地模型（`local-lan/*`）`price_state=local`；`/v1/route/capabilities` 字段集保持既有契约（三态只在 prices 上）。
17. 公开包脱敏：对三件包与 docs-open 各跑一次 `opensource-leak-scan`（若对侧有该工具），应 0 命中；至少人工抽查无内部路径/内部文档名。
